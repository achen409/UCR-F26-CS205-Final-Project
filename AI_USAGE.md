# AI Usage

I stuck with the default trial of ChatGPT as my coding agent. My logic was that if I could complete this project with a simpler and cheaper coding agent, I would be able to use more advanced agents to their full potential. This meant that I would have to lean more into prompt engineering than having a built-in agent in my IDE. I rather enjoyed having this layer of separation between repo and agent because it meant that I was in control of all input and output from the agent.

As I am very rusty with this framework, ChatGPT helped immensly with coding what I envisioned. I gave it the project's structure only with the contents of all relevant files (src folder, how the json file was formatted, etc) and the additions I wanted to see. In the prompt, I instructed the agent to tell me which files were changed and their changes. It also did not hurt to add a small sentence stating "make as little change as possible" and "be brief".

Before I continue, I need to mention that I have the default free trial of ChatGPT so I was limited in how many files I could attach. So, I attached 3 files and copy and pasted the remaining files into the text prompt denoting which file it was. I asked ChatGPT to not start coding until it believed it had all the files it had. This is similiar to the "planning" mode other agents like Cursor offer. Although this process seems inefficient, this process forced me to look through the repository and filter files by importance, getting a better understanding of the repo in the process.

From there ChatGPT, understood the project's file structure and the important files. After this tedious process, I received instructions for what changes needed to be made for each existing file and complete jsx files for new components I would have to copy and paste. I make it an effort to review all agent output before I put it into my code and this project was no different. While many may see how I have to manually integrate agent output into my repo as an inconvenience, I do not because you naturally already have to review agent code before committing. ChatGPT really enjoyed putting unnecessary comments and white-spaces into its code. Since I was reviewing the code before adding it, I easily able to make an effort to clean up the formatting as best I could and remove the frequent comments.
